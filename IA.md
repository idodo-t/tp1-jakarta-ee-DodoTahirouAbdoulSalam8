# Utilisation de l'IA - TP 1

Utilisation 1 : Structure de l'application (JsonAdapter, LlmClient)

Problème rencontré :
Je ne savais pas comment organiser les classes nécessaires pour communiquer avec l'API REST de Gemini en Jakarta EE.

Raison de l'utilisation de l'IA :
J'avais besoin d'aide pour comprendre l'utilisation de JSON-P, du client JAX-RS et leur rôle dans la communication avec une API externe.

Prompt utilisé :
Comment structurer une application Jakarta EE pour communiquer avec l'API Gemini en utilisant JsonAdapter, LlmClient et LlmInteraction ?

Réponse de l'IA :
L'IA m'a proposé une structure basée sur trois composants : la gestion du JSON, les appels HTTP vers Gemini et la représentation des données échangées.

Ce que j'ai appris :
J'ai appris à mieux organiser mon code, à séparer les responsabilités des classes et à comprendre comment envoyer et recevoir des données JSON à travers une API REST.
